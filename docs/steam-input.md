# Controller layout for Game Mode (Steam Input)

Arcadia reads the keyboard, so in Game Mode you only need Steam Input to turn Deck buttons into keys.
Select Arcadia in your Steam library > controller icon > Edit layout (or start from "Gamepad with ... " and change these):

| Deck button | Key | Does |
|---|---|---|
| D-pad up / down / left / right | Up / Down / Left / Right | rotate consoles, browse games |
| Left stick | Up / Down / Left / Right (as D-pad) | same |
| A | Enter | open console, launch game |
| B | Escape | back |
| Y | Ctrl + D | favorite (game screen) |
| Left bumper (L1) | Page Up | previous console |
| Right bumper (R1) | Page Down | next console |
| X | Ctrl + F | search |
| Menu (≡) | F11 | toggle fullscreen |

Tips: set the touchscreen/trackpads to "Mouse" so clicking works; no other buttons are needed.
Emulators you launch from Arcadia get their own controls from the emulator's settings, not from this layout.
This layout has not been tried on a real Deck yet.
