Fixes found by an audit. Quitting Arcadia (or closing it from Steam) while a Setup tool was still working could crash it, as the tool kept writing to a screen that had gone. With no games yet, more settings could make Arcadia close the way changing the colours did in 0.1.3 (Collections, grouping custom collections, the UI mode): with no games, settings are now saved and simply take effect once there are games.
