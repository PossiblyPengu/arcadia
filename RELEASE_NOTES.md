Arcadia is now built on **ES-DE 3.5.0**. PlayStation 2 games can be set up again (the RetroArch core Arcadia used is gone from libretro's server; its replacement, PCEE2, is used now), Switch games get Eden from the Emulators screen, and there are many new emulator choices, video scraping from TheGamesDB, Czech, and upstream's fixes. **Every emulator uses one BIOS folder and one ROM folder**: installed from Arcadia, each emulator finds its BIOS files and keys in ~/Emulation/bios and, opened on its own, lists your games from ~/ROMs (a folder you set yourself in an emulator is never changed, and a changed settings file is backed up first); BIOS files added later are picked up by Check BIOS files. RetroArch's PS2 and Dreamcast cores find their BIOS there too. **Cloud saves connect without a terminal**: Setup → Cloud saves → Connect gets what it needs and signs in to Google Drive with your browser (in Desktop Mode). A game's options (Select in a game list) have **Emulator for this game**. Setup's checklist can be translated, and the screenshots in the docs are up to date.
