Fixes from testing every step on a Steam Deck. Emulators install for the whole Deck, like Discover and Deckhand do (no second copy of their runtimes, which saved 2.4 GB for RetroArch). The game screen shows only the facts a game has (no more "unknown" chips), with a line saying where to get covers and info. The welcome screen follows a colour change; changing the colours or theme with no games no longer upsets anything. Setup and the Emulators screen open and close at once (their checks run in the background, and the setup tools are installed once per run). When nothing on screen changes for a few seconds, Arcadia draws at about 30 frames a second instead of the screen's full rate, to save battery; any input brings the full rate back. Setup, Emulators and the tool window can now be translated. Arcadia says which version it is (--version, and to Deckhand), leaves an uninstaller in ~/Arcadia/deck, and its tools say "NES" and explain what the scraper did.
