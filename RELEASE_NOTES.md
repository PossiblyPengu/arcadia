Emulators that work the first time. Setup's new **Emulators** screen looks at your games and lists what they need first (the emulator Arcadia uses for each console), with **X** to install it all and progress shown line by line. Most classic consoles (PlayStation, SNES, N64, Game Boy Advance and more) play through RetroArch, and the RetroArch app comes without the *cores* that play each console, so before this, installing emulators left those games unable to start; the screen now installs the cores too, from libretro's build server, each checked against the checksum it publishes. Before, *Install emulators* installed all twelve emulators blind; now it installs only what your games need (or the one you pick), adds Flathub for your user first (SteamOS only sets it up system-wide), and lets new emulators see your ROM, BIOS and save folders straight away. Windows games point to Deckhand. Installed emulators can be updated (with their cores) or removed from the same screen.
