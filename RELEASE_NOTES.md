Fixes a crash: with no games yet (a fresh install), changing the colours, the theme or another look setting made Arcadia close. The welcome screen now also follows a change of colours. Emulators that work the first time. Setup's new **Emulators** screen looks at your games and lists what they need first (the emulator Arcadia uses for each console), with **X** to install it all and progress shown line by line. Most classic consoles (PlayStation, SNES, N64, Game Boy Advance and more) play through RetroArch, and the RetroArch app comes without the *cores* that play each console, so before this, installing emulators left those games unable to start; the screen now installs the cores too, from libretro's build server, each checked against the checksum it publishes. Before, *Install emulators* installed all twelve emulators blind; now it installs only what your games need (or the one you pick), adds Flathub for your user first (SteamOS only sets it up system-wide), and lets new emulators see your ROM, BIOS and save folders straight away. Windows games point to Deckhand. Installed emulators can be updated (with their cores) or removed from the same screen. Dialogs and notifications are clearer too: each has a badge that says what it is about (a question, something done, a problem, removing something), dialogs lead with a title, notifications slide in at the top and, when an emulator is missing, say where to install it; the launch screen is no longer in capitals. The window the Setup tools run in is redesigned: a spinner that turns into a tick or an exclamation mark, a status line ("Done in 40 s"), a progress bar for installs, each line shown as what it is (done, a problem, a step, a hint), the result in a tinted box, Try again when something failed, and scrolling with the D-pad for long reports. Settings are simpler: seven sections instead of nine (Collections moved into Look and feel, Tools into Advanced), and each section shows the settings people actually change (Look and feel has nine instead of 34, Advanced six instead of 25), with everything else one press away under "More options". Covers and info speaks plainly ("Get covers and info from", "Which consoles", "What to get", a "Get covers" button) and has your consoles chosen from the start, so it works the first time; the game list options card is centred and tidy, with "Done" and "Cancel" instead of "Close (apply)" and "Close (cancel)". Pressing X on a game with no pictures or video now says so and where to get them.
