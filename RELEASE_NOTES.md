Safer updates, and a sorter fix. Update Arcadia now checks each download against the checksum GitHub lists for it, and refuses a file that doesn't match or a release that lists none; before, it replaced the AppImage and ran a script from the downloaded archive without checking either. Sort downloads now puts ROMs in the folder you already use when a system has two common names (megadrive or genesis, megacd or segacd, tg16 or pcengine) instead of starting a second folder.
