# Tiles that ship with Arcadia

The Recent / Favorites / All collection tiles and the generic cartridge (shown for a console with no logo) are
original to Arcadia, drawn by `tools/make_extra_art.py` (with `tools/isoart.py` and `tools/voxel.py`).

Console pictures are not included: each console is shown with its logo, downloaded to your own machine
(View → Download console logos…, see `arcadia/logos.py`) or with a picture you provide. Console names and logos
belong to their makers and are used only to show which console is which.
